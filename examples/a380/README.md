# A380-800 systems simulation

Electrical, hydraulic, bleed air, fuel, four engines with FADECs, the APU, fire protection and failures for an A380-800, built on EasyAcft. Systems only: there is no cockpit, display or flight model.

Values come from public data, such as Airbus's A380 Aircraft Characteristics, type certificate data sheets and the ICAO engine emissions databank. The files are EasyAcft's own writing.

Open it in Studio to see every system drawn live:

```
easyacft-studio examples/a380
```

Run the cold-start test:

```
easyacft test examples/a380
```
