# EasyAcft

A whole-aircraft systems library for X-Plane: electrical, hydraulic, pneumatic, fuel, engines,
FADEC, APU, failures and breakers, described in TOML files and checked before they run.

Status: milestone M0 (solver core). The plan is in `docs/2026-11-03-easyacft-plan.md`.
